1. Enunciado

Você foi contratado para extrair relatórios de inteligência para uma distribuidora. A diretoria precisa identificar quais vendedores estão atingindo as metas, quais produtos são os mais rentáveis e como está a distribuição de clientes por região. Para isso, você deverá utilizar as funções agregadoras (SUM, AVG, COUNT, MAX, MIN) e as cláusulas de agrupamento e filtragem (GROUP BY e HAVING).

2. Preparação

  • Certifique-se de que o MySQL Workbench está aberto.
  • Utilize o esquema de banco de dados padronizado abaixo.
  • Importante: Se você já possui as tabelas criadas, o script abaixo irá limpá-las e reinserir os dados para garantir que os resultados dos relatórios batam com o gabarito.

3. Código Base (Estrutura e Dados)

Copie e execute o script abaixo para preparar o seu ambiente de testes:


CREATE TABLE vendedores (id INT PRIMARY KEY, nome VARCHAR(50), salario_fixo DECIMAL(10,2));
CREATE TABLE clientes (id INT PRIMARY KEY, nome VARCHAR(50), cidade VARCHAR(30), uf CHAR(2));
CREATE TABLE produtos (id INT PRIMARY KEY, descricao VARCHAR(50), unidade VARCHAR(5), valor_unitario DECIMAL(10,2));
CREATE TABLE pedidos (id INT PRIMARY KEY, id_cliente INT, id_vendedor INT, data_pedido DATE, FOREIGN KEY (id_cliente) REFERENCES clientes(id), FOREIGN KEY (id_vendedor) REFERENCES vendedores(id));
CREATE TABLE itens_pedidos (id_pedido INT, id_produto INT, quantidade INT, PRIMARY KEY (id_pedido, id_produto), FOREIGN KEY (id_pedido) REFERENCES pedidos(id), FOREIGN KEY (id_produto) REFERENCES produtos(id));

4. O Desafio

Escreva as queries SQL para resolver os seguintes problemas de negócio:

  1. Resumo Geral: Qual o valor total vendido pela loja (soma de todas as quantidades multiplicadas pelos valores unitários)?
  2. Média de Preços: Qual a média de preço dos produtos cadastrados na categoria 'L' (unidade)?
  3. Contagem por Região: Quantos clientes cadastrados existem em cada estado (UF)?
  4. Ranking de Vendedores: Liste o nome dos vendedores e o valor total que cada um vendeu. Ordene do maior para o menor faturamento.
  5. Filtro de Metas (Metas > 100): Quais vendedores conseguiram um faturamento total superior a R$ 100,00? (Dica: Use GROUP BY e HAVING).

Orientações Finais

  • Atenção aos Joins: Para os desafios 4 e 5, você precisará unir as tabelas de vendedores, pedidos, itens_pedidos e produtos.
  • Nomenclatura: Utilize Aliases (AS) para que os títulos das colunas nos relatórios fiquem legíveis (ex: AS faturamento_total).
  • O Erro Comum: Lembre-se que se você selecionar o "nome" e o "sum", o nome deve estar obrigatoriamente no GROUP BY.
  • Dica de Ouro: O WHERE filtra os dados antes de você somar, e o HAVING filtra depois que o cálculo está pronto.
