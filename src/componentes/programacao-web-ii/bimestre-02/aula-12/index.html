Teoria & Conceitos: Anatomia de uma Classe

Uma classe em PHP é composta por dois tipos principais de membros: Atributos (que armazenam dados) e Métodos (que definem o comportamento). Juntos, eles permitem que o software seja modelado em torno de entidades do mundo real, como usuários, produtos ou contas bancárias.

1. Atributos (Propriedades)

Os atributos representam o estado de um objeto. Eles funcionam como variáveis internas que guardam as características de cada instância.

  • Definição: Declarados dentro da classe com visibilidade (public, private ou protected).
  • Tipagem (PHP 8+): Recomenda-se definir o tipo (string, int, float) para garantir integridade.
  • Valores Padrão: Podem ter valores iniciais constantes.
class Carro {
    public string $marca;
    public string $modelo;
    public int $ano = 2024; // Valor padrão
}

$meuCarro = new Carro();
$meuCarro->marca = "Toyota";

2. Métodos (Operações)

Os métodos são funções dentro de uma classe que descrevem as ações que o objeto pode realizar ou como ele manipula seus dados.

class Calculadora {
    public function somar(float $a, float $b): float {
        return $a + $b;
    }
}

$calc = new Calculadora();
echo $calc->somar(10, 5); // Saída: 15

3. A Pseudo-variável $this

A pseudo-variável $this é uma autorreferência, permitindo que um método acesse os atributos e outros métodos da instância atual do objeto.

class Produto {
    public string $nome;
    public float $preco;

    public function aplicarDesconto(float $porcentagem): void {
        // $this acessa o preço DESTA instância
        $valorDesconto = $this->preco * ($porcentagem / 100);
        $this->preco -= $valorDesconto; 
    }
}

4. Visibilidade e Encapsulamento

  • public: Acesso de qualquer lugar.
  • private: Acesso apenas por métodos da própria classe (Base do Encapsulamento).
  • protected: Acesso pela própria classe e herdeiros.

5. Observação: Visibilidade de Classes vs. Membros

Diferente do que ocorre com os atributos e métodos, não é possível atribuir modificadores de visibilidade (como public, private ou protected) diretamente à declaração de uma classe no PHP. O funcionamento segue estas regras:

  • Visibilidade de Membros: Os modificadores são projetados para membros (propriedades, métodos e constantes) para controlar o acesso externo aos dados internos.
  • Declaração de Classe: Uma classe é declarada simplesmente com class NomeDaClasse. Uma vez carregada, ela fica disponível no escopo em que foi criada ou dentro de seu Namespace.
  • Uso de Namespaces: O PHP utiliza Namespaces para organizar e restringir logicamente grupos de classes, evitando colisões de nomes, mas não impedem tecnicamente a instanciação se o caminho completo for referenciado.
  • Encapsulamento: O conceito de "esconder" a implementação é aplicado nos membros. Embora o "molde" (classe) seja visível, o acesso ao estado interno é protegido.

Para criar uma estrutura que não possa ser herdada, o PHP oferece a palavra-chave final, que impede que a classe seja estendida por subclasses, embora ela continue disponível para instanciação.

Exemplos de Código

1. Declaração e Acesso Direto

Estrutura simples com atributos públicos e uso básico do $this.

class Pessoa {
    public string $name = "";

    public function setName($newName) {
        // $this refere-se à instância atual do objeto
        $this->name = $newName; 
    }

    public function getName() {
        return $this->name;
    }
}

$ed = new Pessoa();
$ed->setName("Edison");
echo "Olá, " . $ed->getName(); // Saída: Olá, Edison

2. Visibilidade e Encapsulamento

Uso de atributos privados e métodos para manipular o estado do objeto com segurança.

class ItemEstoque {
    private string $produto;
    private int $quantidade = 0;

    public function __construct(string $nome) {
        $this->produto = $nome; // Inicialização via construtor
    }

    public function repor(int $unidades): void {
        $this->quantidade += $unidades; 
    }

    public function exibirStatus(): void {
        echo "Produto: {$this->produto} | Estoque: {$this->quantidade}";
    }
}

$teclado = new ItemEstoque("Teclado");
$teclado->repor(50);
$teclado->exibirStatus();

3. Promoção de Propriedade no Construtor

Recurso moderno que reduz código repetitivo declarando atributos diretamente no construtor.

class Usuario {
    // PHP 8: Atributos declarados e atribuídos automaticamente
    public function __construct(
        private string $nome,
        private string $email
    ) {
        echo "Usuário {$this->nome} criado com sucesso!";
    }

    public function getEmail(): string {
        return $this->email;
    }
}

$user = new Usuario("Ana", "ana@email.com");

4. Interface Fluente (Method Chaining)

Métodos que retornam $this, permitindo o encadeamento de chamadas.

class Pedido {
    private float $total = 0.0;
    private array $itens = [];

    public function adicionarItem(string $nome, float $preco): self {
        $this->itens[] = $nome;
        $this->total += $preco;
        return $this; // Retorna a instância atual
    }

    public function aplicarDesconto(float $valor): self {
        $this->total -= $valor;
        return $this;
    }

    public function finalizar(): void {
        echo "Total do pedido: R$ " . number_format($this->total, 2);
    }
}

// Uso da Interface Fluente
$meuPedido = (new Pedido())
          ->adicionarItem("Monitor", 800.00)
          ->adicionarItem("Mouse", 50.00)
          ->aplicarDesconto(30.00)
          ->finalizar();

Dicas & Lembretes

  • Sintaxe do $this: Ao acessar um atributo via $this, não utilize o cifrão no nome do atributo. Use $this->nome e nunca $this->$nome.
  • Encapsulamento: Mantenha atributos como private ou protected para proteger os dados, usando métodos públicos como interface.
  • Identidade: Mesmo que dois objetos venham da mesma classe, cada um tem seus próprios valores na memória, diferenciados pelo $this.
  • Responsabilidade: Um método deve ter uma responsabilidade clara (ex: validar, calcular ou formatar).

Como aplicar na Prática

Utilize membros da classe para organizar sistemas complexos:

  • Sistemas de Login: Atributos para $email e $senha, e métodos para autenticar().
  • E-commerce: Atributos de $estoque protegidos, permitindo alteração apenas via métodos que validam a disponibilidade.
