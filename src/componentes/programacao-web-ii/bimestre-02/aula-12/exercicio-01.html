Enunciado

Nesta atividade, você desenvolverá o motor de um player de música utilizando Programação Orientada a Objetos. O sistema deve permitir a criação de músicas individuais e a organização delas em uma playlist. O grande desafio é garantir que cada música mantenha sua própria identidade (título, artista, álbum e arquivo) e que a playlist consiga gerenciar essa coleção de objetos para que o player funcione no navegador.

Preparação

  1. Crie uma pasta para o projeto chamada player_poo.
  2. Dentro dela, crie uma subpasta chamada musicas e coloque nela 2 ou 3 arquivos .mp3.
    • Dica: Renomeie os arquivos para um padrão simples, ex: linkinpark-numb.mp3.
  3. Crie os arquivos Musica.php, Playlist.php e index.php na raiz da pasta do projeto.

O Desafio (A Atividade)

Com as classes estruturadas, você deve configurar o arquivo index.php para realizar a montagem manual do sistema:

  1. Instanciação da Playlist: No topo do index.php, crie um objeto da classe Playlist passando o nome e o nome da pasta onde estão os arquivos (ex: "musicas").
  2. Instanciação das Músicas: Crie pelo menos duas instâncias da classe Musica. No parâmetro do arquivo, digite exatamente o nome do arquivo que está na pasta (ex: "linkinpark-numb.mp3").
  3. Associação: Utilize o método adicionar() da sua playlist para inserir os objetos de música criados.
  4. Exibição: Use o código HTML/PHP para o index.php em Código Base no seu index.php para renderizar o player.

Orientações Finais

  • O Papel do $this: Observe que, ao clicar no botão, o PHP usa $m->getArquivo(). Dentro da classe, o $this garante que o arquivo retornado seja exatamente o daquela música específica clicada, e não de outra.
  • Encapsulamento: Verifique se você consegue acessar $m->titulo diretamente no index.php. Se o PHP der erro, parabéns! Seu encapsulamento está funcionando e o dado está protegido, acessível apenas via método.
  • Teste Real: Abra o terminal na pasta do projeto e execute php -S localhost:8000. Se ao clicar na música o som começar a tocar, sua arquitetura de objetos foi implementada com sucesso.
