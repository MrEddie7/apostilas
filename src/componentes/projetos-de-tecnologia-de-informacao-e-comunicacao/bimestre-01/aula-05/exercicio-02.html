Enunciado

Utilizando o documento criado no Exercício 01, siga as etapas abaixo para organizar os elementos pré-textuais:

  1. Inserir Folha de Rosto:
    • Acesse a guia Inserir > Folha de Rosto.
    • Escolha um modelo sóbrio ou crie uma manualmente contendo: Nome da Instituição, Seu Nome, Título do Trabalho, Cidade e Ano.
  2. Inserir Quebra de Página:
    • Após a folha de rosto, use o atalho Ctrl + Enter para criar uma página em branco destinada ao Sumário.
  3. Gerar Sumário Automático:
    • Na página em branco criada, acesse a guia Referências > Sumário.
    • Selecione Sumário Automático 1.
    • Verifique se os títulos "1 INTRODUÇÃO", "1.1 OBJETIVOS" e "2 DESENVOLVIMENTO" aparecem corretamente com suas respectivas páginas.
  4. Simulação de Alteração:
    • Mova o título "2 DESENVOLVIMENTO" para uma nova página (usando Ctrl + Enter).
    • Clique com o botão direito sobre o sumário e selecione Atualizar Campo > Atualizar o índice inteiro. Verifique se o número da página foi corrigido automaticamente.

Desafio Extra

Tente inserir uma Nota de Rodapé na palavra "ABNT" explicando o que significa a sigla, utilizando a guia Referências > Inserir Nota de Rodapé.
