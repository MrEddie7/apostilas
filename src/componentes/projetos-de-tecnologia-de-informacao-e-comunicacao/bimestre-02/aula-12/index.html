Teoria & Conceitos

Esta aula foca no domínio das fórmulas e funções, que representam a real vantagem competitiva no uso de planilhas eletrônicas como o Microsoft Excel. Elas permitem relacionar conteúdos de células para automatizar cálculos complexos, essenciais para o perfil do Técnico em Contabilidade.

1. O que são Fórmulas e Funções?

  • Fórmulas: São equações criadas pelo usuário para executar cálculos sobre valores na planilha. Elas podem conter números, referências de células (como A1 ou B5), operadores matemáticos e funções.
  • Funções: São "fórmulas pré-gravadas" ou pré-definidas que aceitam valores, executam uma operação específica e retornam um resultado. Elas simplificam a planilha, especialmente em cálculos extensos.

Regra de Ouro: Toda fórmula ou função deve obrigatoriamente começar com o sinal de igual (=). Sem ele, o Excel interpretará o conteúdo apenas como texto ou data.

2. Operadores Matemáticos e Precedência

Para realizar cálculos, utilizamos operadores que indicam o tipo de operação.

Operador Operação Exemplo
+ Adição =A1+B1
- Subtração =A1-B1
* Multiplicação =A1*B1
/ Divisão =A1/B1
% Porcentagem =A1*10%
^ Exponenciação =A1^2

Ordem de Precedência (Prioridade)

Quando uma fórmula tem vários operadores, o Excel segue uma ordem para resolver o cálculo:

  1. Parênteses ( ): Tudo que estiver dentro deles é resolvido primeiro.
  2. Exponenciação ^.
  3. Multiplicação * e Divisão /.
  4. Adição + e Subtração -.

Exemplo: Em =5+2*10, o resultado é 25 (multiplicação primeiro). Em =(5+2)*10, o resultado é 70 (parênteses primeiro).

3. Anatomia de uma Função

Toda função segue uma estrutura padrão: =NOME_DA_FUNÇÃO(argumento1; argumento2; ...)

  • Nome: Identifica a ação (ex: SOMA, MÉDIA).
  • Parênteses: Obrigatórios após o nome para indicar onde os argumentos começam e terminam.
  • Argumentos: São os valores ou referências que a função usará para calcular. Podem ser números, textos, ou intervalos de células.
  • Separadores: Usamos ponto e vírgula (;) para separar argumentos individuais e dois pontos (:) para indicar um intervalo contínuo.

4. Principais Funções Matemáticas e Estatísticas

SOMA

Adiciona todos os números em um intervalo de células.

  • Exemplo: =SOMA(A1:A10) soma todos os valores da célula A1 até a A10.

MÉDIA

Retorna a média aritmética dos argumentos.

  • Exemplo: =MÉDIA(B1:B5) soma os valores de B1 a B5 e divide por 5.

MÁXIMO e MÍNIMO

Identificam, respectivamente, o maior e o menor valor de um conjunto.

  • Exemplo: =MÁXIMO(C1:C100) mostra o maior valor encontrado nesse intervalo.

RAIZ

Calcula a raiz quadrada de um número.

  • Exemplo: =RAIZ(64) retornará 8.

5. Funções Lógicas para Automação

As funções lógicas permitem que a planilha "tome decisões" com base em critérios, retornando valores como VERDADEIRO ou FALSO.

Operadores de Comparação

Usados dentro das funções lógicas para testar valores:

  • = (Igual), > (Maior), < (Menor), >= (Maior ou igual), <= (Menor ou igual), <> (Diferente).

Função SE (IF)

É uma das funções mais poderosas. Ela verifica uma condição e devolve um resultado se for verdadeira e outro se for falsa.

  • Sintaxe: =SE(teste_lógico; valor_se_verdadeiro; valor_se_falso).
  • Exemplo Prático (Situação Escolar): Imagine que a média para aprovação é 6. Na célula C2 está a média do aluno. =SE(C2>=6; "APROVADO"; "REPROVADO"). Se C2 for 7, o Excel escreverá "APROVADO". Se for 5, escreverá "REPROVADO".
  • SE Aninhado: Você pode colocar um "SE" dentro de outro para testar múltiplas condições (até 7 níveis). Exemplo: =SE(A1>89;"A";SE(A1>79;"B";"C")).

Função E (AND)

Retorna VERDADEIRO apenas se todas as condições testadas forem verdadeiras.

  • Exemplo: =E(A1>10; B1<5) só será verdadeiro se A1 for maior que 10 e B1 for menor que 5 simultaneamente.

6. Tratamento de Erros: Função SEERRO

Muitas vezes, uma fórmula pode gerar erros como #DIV/0! (divisão por zero) ou #VALOR! (tipo de dado inválido). A função SEERRO permite personalizar o que aparece quando algo dá errado, evitando que a planilha fique com aspecto amador.

  • Sintaxe: =SEERRO(valor; valor_se_erro).
  • Exemplo: =SEERRO(A1/B1; "Cálculo Indisponível"). Se B1 for zero, ao invés do erro padrão, aparecerá o texto "Cálculo Indisponível".

Dica de Produtividade: AutoSoma

O Excel possui o botão AutoSoma na guia Página Inicial. Ao clicá-lo, o programa identifica automaticamente o intervalo de números vizinhos e escreve a função =SOMA() para você, bastando pressionar ENTER para confirmar.
