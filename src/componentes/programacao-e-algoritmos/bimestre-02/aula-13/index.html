Teoria & Conceitos

As estruturas de controle são os mecanismos que permitem ao computador tomar decisões e repetir tarefas, fugindo da execução linear linha a linha. Nesta aula, avançamos para o estudo de decisões que não são apenas binárias (verdadeiro ou falso), mas que envolvem múltiplos caminhos e refinamentos lógicos através do aninhamento de condições e da estrutura de seleção múltipla (switch-case).

1. Ninhos de SE (Decisões Aninhadas)

O aninhamento ocorre quando uma estrutura if ou if-else é colocada dentro do bloco de comandos de outra estrutura condicional. Essa técnica é utilizada quando o caminho para a tomada de uma decisão forma uma árvore com diversas ramificações, onde uma condição interna só é avaliada se a condição externa for satisfeita.

Cenário 1: Classificação de Triângulos

Para determinar o tipo de um triângulo, primeiro precisamos verificar se ele existe. Só então aninhamos as decisões para saber se ele é equilátero, isósceles ou escaleno. 

// Exemplo de ninhos de SE para classificação de triângulos
if (a < b + c && b < a + c && c < a + b) { // Condição externa (existência)
    if (a == b && a == c) { // Primeiro nível de aninhamento
        System.out.println("Equilátero!");
    } else {
        if (a == b || a == c || b == c) { // Segundo nível de aninhamento
            System.out.println("Isósceles!");
        } else {
            System.out.println("Escaleno!");
        }
    }
} else {
    System.out.println("O triângulo não existe!");
}

O Problema do "Dangling else"

Um erro comum em ninhos de SE sem o uso de chaves { } é a ambiguidade do else. Em Java, o compilador sempre associa o else ao if mais próximo. Para evitar comportamentos inesperados, a boa prática exige o uso de chaves para delimitar claramente os blocos.

2. Estrutura Encadeada (if-else if)

Embora tecnicamente seja uma forma de aninhamento, o encadeamento if-else if-else é uma maneira mais elegante de lidar com intervalos de valores ou situações onde apenas um entre vários blocos deve ser executado.

Cenário 2: Cálculo de IMC (Índice de Massa Corpórea)

Diferente do switch-case (que veremos abaixo), o aninhamento com if permite trabalhar com faixas numéricas e valores do tipo double. 

// Estrutura encadeada para intervalos de valores
double imc = peso / (altura * altura);

if (imc < 20) {
    System.out.println("Você está magro!");
} else if (imc <= 25) { // IMC entre 20 e 25
    System.out.println("Você está num bom peso!");
} else { // IMC maior que 25
    System.out.println("Você está gordo!");
}

3. Seleção Múltipla (switch-case)

A estrutura switch permite testar o valor de uma única expressão contra diversos valores constantes. Ela é mais simples e legível que múltiplos ifs aninhados quando se trata de escolhas pontuais e discretas.

  • Tipos permitidos em Java: int, short, byte, char e tipos enumerados (enums).
  • Restrições: Não aceita valores reais (double/float) ou expressões de comparação (como > 10) nos rótulos case.

Componentes do Switch:

  • case: Marca o ponto onde a execução deve "pular" se o valor coincidir com a expressão.
  • break: Interrompe a execução e sai do bloco switch. Se omitido, o código continuará executando os casos seguintes ("fall-through"), o que raramente é desejado.
  • default: Bloco opcional executado caso nenhuma das opções anteriores seja verdadeira. Funciona como uma mensagem de erro ou opção padrão.

Cenário 3: Menu de Conversão de Unidades

// Exemplo de switch-case para processamento de menus
System.out.println("1. polegadas | 2. pés | 3. jardas | 4. milhas");
int opcao = leitor.nextInt();

switch (opcao) {
    case 1:
        System.out.println("Conversão para polegadas selecionada.");
        break;
    case 2:
        System.out.println("Conversão para pés selecionada.");
        break;
    case 3:
    case 4: // Casos agrupados: mesma ação para jardas ou milhas
        System.out.println("Conversão para unidades longas selecionada.");
        break;
    default:
        System.out.println("Opção inválida!!"); 
}

4. Definite Assignment (Atribuição Definitiva)

Ao usar switch ou if aninhados para atribuir valor a uma variável, o Java exige que você garanta que ela receba um valor em todos os caminhos possíveis. Se houver uma falha lógica onde a variável possa ficar sem valor, o compilador gerará um erro.

Dica Prática: Sempre que possível, utilize o default no switch para garantir que a lógica seja concluída com sucesso mesmo diante de entradas inesperadas.

Exemplo de Código

Exemplo 1: Classificação de Triângulos (Ninhos de SE)

Utilizando a lógica de existência e classificação posterior.

public class ClassificaTriangulo {
    public static void main(String[] args) {
        double a = 5, b = 5, c = 5;

        if (a < b + c && b < a + c && c < a + b) {
            if (a == b && a == c) {
                System.out.println("Equilátero");
            } else {
                if (a == b || a == c || b == c) {
                    System.out.println("Isósceles");
                } else {
                    System.out.println("Escaleno");
                }
            }
        } else {
            System.out.println("Não é um triângulo.");
        }
    }
}

Exemplo 2: Menu com Switch-Case

Implementação de um menu interativo simples.

import java.util.Scanner;

public class MenuConversao {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);
        
        System.out.println("Escolha uma opção:");
        System.out.println("1. Metros para Centímetros");
        System.out.println("2. Metros para Quilômetros");
        System.out.println("0. Sair");
        
        int opcao = leitor.nextInt();
        
        switch (opcao) {
            case 1:
                System.out.println("Convertendo para centímetros...");
                break;
            case 2:
                System.out.println("Convertendo para quilômetros...");
                break;
            case 0:
                System.out.println("Saindo do sistema.");
                break;
            default:
                System.out.println("Opção inválida!");
        }
        leitor.close();
    }
}

Dicas & Lembretes

  • Uso do Break: No switch, o break é fundamental. Sem ele, o Java executa todos os casos abaixo do que foi selecionado (efeito fall-through).
  • Clareza: Se você tem mais de 3 níveis de aninhamento de ifs, considere refatorar seu código ou usar switch-case para melhorar a legibilidade.
  • Default: Sempre inclua uma cláusula default no switch para tratar valores inesperados e garantir a atribuição definitiva.
  • Tipos de Dados: Lembre-se que o switch não aceita números decimais (float/double) nem intervalos (ex: case x > 10).

Como aplicar na Prática

  • Menus de Usuário: Criação de menus textuais onde o usuário escolhe opções numeradas.
  • Classificações Complexas: Situações onde uma regra de negócio depende de várias outras pré-condições (como o exemplo do triângulo).
  • Máquinas de Estado: Controle do estado de um jogo ou aplicação (ex: Menu -> Jogando -> Pausado -> Game Over).
