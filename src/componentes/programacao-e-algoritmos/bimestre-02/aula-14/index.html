Teoria & Conceitos: Estruturas de Repetição (while e do-while)

As estruturas de repetição (laços ou loops) permitem que um conjunto de instruções seja executado várias vezes até que uma condição específica seja atingida. Elas são essenciais para processar grandes quantidades de dados ou automatizar tarefas repetitivas sem a necessidade de duplicar linhas de código manualmente.

1. O Comando while (Teste no Início)

O while é a estrutura de repetição mais básica, funcionando como uma "decisão repetida". Ela é classificada como uma estrutura de pré-teste, o que significa que a condição de parada é verificada antes de qualquer instrução do corpo ser executada.

  • Funcionamento: Se a condição for falsa logo na primeira avaliação, o corpo do laço nunca será executado.
  • Sintaxe em Java:

Exemplo: Contagem Sequencial

int contador = 1; 
while (contador <= 5) { 
    System.out.println("Número: " + contador);
    contador++; // Atualização obrigatória para evitar laço infinito
}

2. O Comando do-while (Teste no Fim)

A estrutura do-while é muito semelhante ao while, mas com uma diferença crucial: ela é uma estrutura de pós-teste. O teste da condição de controle é realizado apenas após a execução do bloco de comandos.

  • Funcionamento: Devido ao teste ocorrer no final, o corpo do laço é obrigatoriamente executado pelo menos uma vez, mesmo que a condição seja falsa desde o início.
  • Atenção à Sintaxe: Diferente do while simples, o do-while exige um ponto-e-vírgula (;) imediatamente após o fechamento dos parênteses da condição.
  • Sintaxe em Java:

Exemplo: Interação com o Usuário
Esta estrutura é ideal para menus ou situações onde você precisa que o usuário realize uma ação antes de perguntar se ele deseja repetir.

boolean querContinuar;
do {
    System.out.println("Executando tarefa do sistema...");
    System.out.print("Deseja rodar novamente? (true/false): ");
    querContinuar = leitor.nextBoolean(); // Captura a decisão do usuário
} while (querContinuar);

3. Cenários Comuns de Aplicação

  • Validação de Entrada de Dados: O while garante que o programa não prossiga enquanto o usuário não fornecer um dado válido (ex: um número positivo).
  • Valores Sentinela: Utiliza-se um valor especial (como 0 ou -1) para marcar o fim de uma sequência de dados quando não se sabe previamente o número de repetições.
  • Processamento de Menus: O do-while é frequentemente usado para exibir um menu ao menos uma vez e mantê-lo ativo até que a opção "Sair" seja escolhida.

Exemplos de Código

1. Nível Básico: Contadores Simples (A Diferença Visual)

Objetivo: Mostrar a sintaxe limpa de ambos e como o do-while garante que o bloco rode pelo menos uma vez, mesmo que a condição seja falsa logo de cara.

public class ExemploBasico {
    public static void main(String[] args) {
        System.out.println("--- USANDO WHILE ---");
        int contadorWhile = 5;
        // Testará a condição ANTES de entrar. Como 5 não é menor que 5, NÃO RODA.
        while (contadorWhile < 5) {
            System.out.println("While: " + contadorWhile);
            contadorWhile++;
        }

        System.out.println("\n--- USANDO DO-WHILE ---");
        int contadorDo = 5;
        // Executa o bloco primeiro, e SÓ DEPOIS testa a condição. RODA 1 VEZ.
        do {
            System.out.println("Do-While: " + contadorDo);
            contadorDo++;
        } while (contadorDo < 5);
    }
}

2. Nível Intermediário: Validação de Entrada de Dados

Objetivo: Demonstrar o uso do do-while para travar o programa até que o usuário digite uma informação válida. Este é o cenário mais clássico e elegante para o do-while.

import java.util.Scanner;

public class ValidacaoDados {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int nota;

        // O programa DEVE pedir a nota ao menos uma vez. 
        // Se for inválida (menor que 0 ou maior que 10), ele repete o pedido.
        do {
            System.out.print("Digite uma nota válida (0 a 10): ");
            nota = scanner.nextInt();
            
            if (nota < 0 || nota > 10) {
                System.out.println("Nota inválida! Tente novamente.");
            }
        } while (nota < 0 || nota > 10);

        System.out.println("Nota cadastrada com sucesso: " + nota);
        scanner.close();
    }
}

3. Nível Avançado: Menu Iterativo (Menu de Opções)

Objetivo: Criar a estrutura padrão de menus para sistemas de console. O do-while mantém o programa rodando até que a opção de saída seja explicitamente escolhida.

import java.util.Scanner;

public class MenuSistema {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int opcao;

        do {
            System.out.println("\n=== MENU PRINCIPAL ===");
            System.out.println("1 - Consultar Saldo");
            System.out.println("2 - Realizar Depósito");
            System.out.println("3 - Sair do Sistema");
            System.out.print("Escolha uma opção: ");
            opcao = scanner.nextInt();

            // Processa a opção escolhida usando um switch/case
            switch (opcao) {
                case 1:
                    System.out.println("-> Seu saldo é R$ 1.500,00");
                    break;
                case 2:
                    System.out.println("-> Depósito realizado com sucesso.");
                    break;
                case 3:
                    System.out.println("Encerrando o sistema... Até logo!");
                    break;
                default:
                    System.out.println("Opção inválida! Escolha 1, 2 ou 3.");
            }

        } while (opcao != 3); // O loop continua enquanto a opção NÃO for 3

        scanner.close();
    }
}

4. Nível "Hero": Processamento Assíncrono / Leitura de Arquivo Simulada

Objetivo: Mostrar o while sendo usado no mundo real (como em conexões de banco de dados, leitura de arquivos ou servidores), onde não sabemos quantas linhas de dados existem (iteração indeterminada), simulando um sensor de dados.

import java.util.Random;

public class ProcessamentoSensores {
    public static void main(String[] args) throws InterruptedException {
        Random geradorAleatorio = new Random();
        
        System.out.println("Iniciando monitoramento de temperatura crítica...");
        
        // Loop infinito controlado (Sinalizador / Flag)
        boolean monitorando = true;

        while (monitorando) {
            // Simula a leitura de um sensor de temperatura (entre 20°C e 45°C)
            int temperaturaAtual = geradorAleatorio.nextInt(26) + 20;
            System.out.println("Temperatura atual: " + temperaturaAtual + "C");

            // Regra de parada (Break / Mudança de Flag)
            if (temperaturaAtual > 40) {
                System.out.println("ALERTA: Superaquecimento detectado (" + temperaturaAtual + "C)!");
                System.out.println("Desligando o monitoramento para segurança do hardware.");
                
                monitorando = false; // Quebra a condição do while na próxima volta
            }

            // Pausa o código por 500 milissegundos para simular o tempo real
            Thread.sleep(500);
        }
    }
}

Representação Gráfica

Fluxograma do while (Pré-Teste)

Observe que a condição é verificada antes de executar o bloco. Se falsa na primeira vez, o bloco é ignorado completamente.

flowchart TD A([Início]) --> B[Inicializa variável de controle] B --> C{Condição verdadeira?} C -- Não --> E([Fim]) C -- Sim --> D[Executa bloco de comandos] D --> F[Atualiza variável de controle] F --> C

Fluxograma do do-while (Pós-Teste)

Aqui o bloco é executado antes da verificação. Isso garante ao menos uma execução, independente da condição.

flowchart TD A([Início]) --> B[Inicializa variável de controle] B --> C[Executa bloco de comandos] C --> D[Atualiza variável de controle] D --> E{Condição verdadeira?} E -- Sim --> C E -- Não --> F([Fim])

Dicas & Lembretes

  • Evite loops infinitos: Sempre garanta que a variável de controle seja modificada dentro do laço (ex.: contador++), caso contrário o programa travará.
  • while vs. do-while: Use while quando o bloco pode não precisar executar nenhuma vez. Use do-while quando o bloco deve executar obrigatoriamente ao menos uma vez (ex.: menus, validações de input).
  • Variável de flag: Em loops com condições complexas, uma variável booleana (boolean rodando = true) torna o código mais legível do que condições muito longas.
  • Cuidado com o ponto e vírgula: O do-while exige ; após o parêntese de fechamento da condição. Esquecer isso gera um erro de compilação.
  • Prefira for quando souber o número de iterações: O while brilha em situações de iteração indeterminada. Quando o número de repetições é conhecido, o for é mais expressivo.

Como aplicar na Prática

As estruturas while e do-while estão presentes em praticamente todos os sistemas do mundo real. Veja onde você as encontrará:

  • Sistemas de Login: Um loop do-while exibe o formulário de login e repete enquanto as credenciais forem inválidas, garantindo que o usuário sempre veja o formulário ao menos uma vez.
  • Leitura de Arquivos: Um while lê linha a linha de um arquivo até que não haja mais conteúdo (while (scanner.hasNextLine())). Não sabemos quantas linhas o arquivo tem, por isso o while é ideal.
  • Conexão com Banco de Dados (ResultSet): Ao buscar registros no banco, iteramos com while (resultSet.next()) até processar todas as linhas retornadas pela consulta SQL.
  • Servidores e Daemons: Servidores web rodam dentro de um while (true) aguardando novas requisições de clientes indefinidamente, encerrando apenas com uma flag de desligamento.
  • Jogos (Game Loop): Todo jogo possui um loop principal (while (jogoRodando)) que atualiza o estado do jogo e redesenha a tela a cada frame.
